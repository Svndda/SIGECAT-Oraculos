## Checklist de funcionalidades probadas

### 1. Acceso al sistema
- [ ] Inicié sesión con mi correo institucional y contraseña.
- [ ] El sistema mostró mi nombre y rol correctamente tras iniciar sesión.
- [ ] Pude cerrar sesión sin problemas.
- [ ] (Si aplica) Probé la recuperación de contraseña.

### 2. Módulo administrativo — Estructura organizacional
*(Solo si el rol probado fue Administrador)*
- [ ] Creé un **área** nueva.
- [ ] Edité un área existente.
- [ ] Eliminé (o desactivé) un área.
- [ ] Creé un **departamento** asociado a un área.
- [ ] Creé una **sección**.
- [ ] Creé una **unidad**.
- [ ] Creé un **cargo** (tipo de puesto).
- [ ] Creé una **plaza** y la asocié a un cargo y a una entidad organizacional.

### 3. Módulo administrativo — Catálogos
- [ ] Creé una **función oficial** asociada a un cargo.
- [ ] Edité una función oficial.
- [ ] Revisé el listado de **funciones personalizadas** creadas por empleados.
- [ ] Creé un **tipo de licencia**.

### 4. Módulo administrativo — Usuarios
- [ ] Creé un usuario nuevo (funcionario).
- [ ] Cambié el rol de un usuario.
- [ ] Desactivé/eliminé un usuario.
- [ ] Restauré un usuario eliminado.

### 5. Módulo administrativo — Declaraciones y registros
- [ ] Consulté el listado de declaraciones de los funcionarios.
- [ ] Revisé el detalle de una declaración (funciones, licencias, descansos).
- [ ] Consulté el módulo de **registros/logs** del sistema.

### 6. Módulo de funcionario — Declaración de jornada
*(Solo si el rol probado fue Funcionario/Empleado)*
- [ ] Inicié una nueva declaración de carga de trabajo.
- [ ] Completé los datos del formulario inicial (cargo, jornada, etc.).
- [ ] Reporté una **función oficial** de mi cargo.
- [ ] Creé y reporté una **función personalizada** (de apoyo condicional).
- [ ] Registré una **licencia** dentro de mi declaración.
- [ ] Registré un **tiempo de descanso**.
- [ ] Agregué información/justificación adicional cuando el sistema la solicitó.
- [ ] Completé y envié la declaración exitosamente.
- [ ] Pude ver el historial de mis declaraciones anteriores.
- [ ] Exporté o descargué una declaración en PDF.

### 7. Ajustes y accesibilidad
- [ ] Accedí a la pantalla de **ajustes de cuenta**.
- [ ] Cambié mi contraseña desde el sistema.
- [ ] Probé las opciones de accesibilidad (tamaño de letra, contraste, fuente para dislexia, etc.).

### 8. Experiencia general
- [ ] La navegación entre pantallas fue clara e intuitiva.
- [ ] Los mensajes de error y confirmación fueron comprensibles.
- [ ] No encontré errores que impidieran completar las tareas anteriores.
